Research Edu-Tools

概要

Research Edu-Toolsは、教育・調査研究用途のWebツールを提供しています。 本ポリシーは、そのうちChannel Data Toolにおける Googleユーザーデータの取り扱いについて定めるものです。

取得する情報

Channel Data Toolは、Google OAuthを利用して、 ユーザーが許可したYouTubeチャンネルのデータを取得します。

YouTube Data API

動画ID、動画タイトル、公開日時、再生回数を取得します。

YouTube Analytics API

動画および日付ごとの分析データとして、 再生回数、総再生時間、平均視聴率、高評価、 コメント、共有、登録者増加数、登録者減少数を取得します。

利用目的

取得したデータは、YouTubeチャンネルの調査・分析および 分析用データの作成に利用します。

データの保存

取得したYouTubeデータは、調査・分析および 分析用データの作成に必要な範囲で、 Google DriveおよびGoogle Spreadsheetに保存します。

OAuth認証情報

Channel Data Toolは、YouTube APIへのアクセスに必要な OAuth認証情報を、APIを利用するために使用します。

第三者への提供

取得したGoogleユーザーデータを、第三者に販売または提供しません。
